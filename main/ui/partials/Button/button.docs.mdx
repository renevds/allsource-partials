## Configurable responsive button with different classes.


### Button with image
```js
<Button src="./arrow_right.svg" className="subscribe">
```
Plus any other html buttons props, for possible classes see below.
On small screens title is removed and buttons just contains image.
### Button without image
```js
<Button className="subscribe">
```
Plus any other html buttons props, for possible classes see below.

### CSS Options
- normal
- filters
- active\_\_filter
- submit
- subscribe
- hot\_\_takes\_\_button\_\_icon
- hot\_\_takes\_\_button\_\_icon\_\_filled
- primarybutton
- secondarybutton
