## Navbarlink

Link component for the navbar that can have different actions.

### Component usage

```js
<Navbar>
    <NavbarLink ...>...</NavbarLink>
  </Navbar>
```

## Local react-router link
```js
    <NavbarLink link='/test'>Test</NavbarLink>
```

## External link
```js
    <NavbarLink href="https://test.com">Test</NavbarLink>
```

## Function call
```js
    <NavbarLink onClick={() => console.log("test")}>Test</NavbarLink>
```
