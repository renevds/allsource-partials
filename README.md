# Allsource component repo

Contains bit.dev components used throughout the Allsource frontend nodes.   
Bit.dev components are **NOT** the same as react components, but they can be.   
They are reusable individually versioned pieces of code. (In this case parts of the frontend).   
This file contains components used troughout the react frontends, these are react components as well as
pieces of js code such as axios configs.

### File structure
Under `main`:
- `partials` contains all shared react components like buttons, are compiled as react
- `style` contains components that are shared css files, are components as node
- `config` contains shared configs like axios configs, are compiled as react

`global` contains the react bit config used to compile our react components   
`.bitmap` is generated by bit.dev and contains the config of all local components (do not edit)      
`workspace.jsonc` contains the bit.dev config   
`public` is generated by bit.dev, can be ignored

### Local development
- `bit link --target ../PATH/TO/PROJECT` replaces node modules in target with sim links to components here
- `bit watch` automatically compiles your components so you get live updates in your target project
- `bit start` runs the bit UI locally so you can view your components and test their docs and previews   
  (can be unstable needs to be restarted sometimes)

### Before deploying checklist
- All changed/new components are working correctly
- No accidental changes were made to other components
- All components have necessary documentation    
- Components have been checked using `bit start`   
(simple ex for small stuff like buttons, more in depth docs for configurable components like the navbar)
- Components names are correct (you can check in .bitmap)
- `npm login` is ran with a user that has acces to the @allsource scope

### Deploying
***Make sure the above checklist is completed.***
- `bit link --rewire` replaces local imports to other components with imports to their npm repo
- `bit tag` tages all changed components a with a new version number and uploads to npm   
(you will need to be logged in to an npm account with access to the organisation)
- `bit export` uploads npm components to the bit repo at [bit.cloud/allsource](https://bit.cloud/allsource).

### Adding/Creating components
- `bit add {path} -i {name}` to add component at folder   
ex: `bit add main/ui/partials/navbar/navbar -I ui/partials/navbar/navbar`
- `bit rename {old} {new}` to rename components

### Files in a component
- `index.js` exports everything this component exposes
- `{name}.composition.jsx` exports react components for examples of this component
- `{name}.docs.jsx` [MDX](https://mdxjs.com/) documentation for this component
- Rest is up to you.
