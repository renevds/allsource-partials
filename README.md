# Allsource component repo

Contains bit.dev components used throughout the Allsource frontend nodes.   
Bit.dev components are **NOT** the same as react components, but they can be.   
They are reusable individually versioned pieces of code. (In this case parts of the frontend).   
The global bit repo contains components used troughout the react frontends, these are react components as well as
pieces of js code such as axios configs.

## Using a component
If you simply want to use a component (not edit it) you can install it like any other npm package.
