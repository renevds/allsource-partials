## UserIconsMobile

Shared Navbar that can be filled with several NavbarLinks.

### Component usage
```js
<Navbar>
    <NavbarLink href='https://google.com'>Hot Takes</NavbarLink>
    <NavbarLink link='/'>Project Directory<Live/></NavbarLink>
    <NavbarLink call={() => console.log("test")}>Test<Live/></NavbarLink>
</Navbar>
```
